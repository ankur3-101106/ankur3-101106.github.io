Permutation, Combinations and Probability​

1. Permutations​

A permutation is an arrangement of objects in a definite order. The order of selection matters.

1.1 Fundamental Principles of Counting​

Multiplication Principle (AND Rule)​

If an operation can be performed in mmm different ways, and following it a second operation can be performed in nnn different ways, then the two operations in succession can be performed in: Total Ways=m×n\text{Total Ways} = m \times nTotal Ways=m×n

Addition Principle (OR Rule)​

If two tasks are mutually exclusive such that the first can be performed in mmm ways and the second in nnn ways, then either the first or the second task can be performed in: Total Ways=m+n\text{Total Ways} = m + nTotal Ways=m+n

1.2 Repetition of Events​

If an event can occur in nnn different ways, the number of ways in which rrr such events can occur when repetition is permitted is: Total Ways=nr\text{Total Ways} = n^rTotal Ways=nr

1.3 Factorial Representation​

The continued product of the first nnn natural numbers is called factorial nnn, denoted by n!n!n! or ⌊n\lfloor{n}⌊n: n!=n×(n−1)×(n−2)×⋯×3×2×1n! = n \times (n - 1) \times (n - 2) \times \dots \times 3 \times 2 \times 1n!=n×(n−1)×(n−2)×⋯×3×2×1 Special values: 0!=1,1!=1,2!=2,3!=6,4!=24,5!=120,6!=720,7!=50400! = 1, \quad 1! = 1, \quad 2! = 2, \quad 3! = 6, \quad 4! = 24, \quad 5! = 120, \quad 6! = 720, \quad 7! = 50400!=1,1!=1,2!=2,3!=6,4!=24,5!=120,6!=720,7!=5040

1.4 Linear Permutations​

The number of permutations of nnn distinct objects taken rrr at a time without repetition is: nPr=n!(n−r)!=n(n−1)(n−2)…(n−r+1)^n P_r = \frac{n!}{(n - r)!} = n(n - 1)(n - 2)\dots(n - r + 1)nPr​=(n−r)!n!​=n(n−1)(n−2)…(n−r+1)

  • When r=nr = nr=n: nPn=n!^n P_n = n!nPn​=n!
  • When r=0r = 0r=0: nP0=1^n P_0 = 1nP0​=1

Permutations of Objects Not All Distinct​

The number of mutually distinguishable permutations of nnn objects where ppp are of one kind, qqq of a second kind, and rrr of a third kind is: Ways=n!p!⋅q!⋅r!\text{Ways} = \frac{n!}{p! \cdot q! \cdot r!}Ways=p!⋅q!⋅r!n!​

The "Tie Together" (String) Method​

When specific items must always occur together:

  1. Treat the group of items as a single compound entity.
  2. Arrange the remaining items along with this compound entity.
  3. Multiply by the internal arrangements of the grouped items.

The "Gap" Method​

When specific items must never occur together:

  1. First arrange the items that have no restrictions.
  2. Place the restricted items into the empty gaps created between and at the ends of the arranged items.

1.5 Circular Permutations​

Arranging nnn distinct objects around a closed circle:

  • Since rotational shifts represent identical configurations, fixing one reference position leaves (n−1)(n - 1)(n−1) positions to fill: Circular Permutations=(n−1)!\text{Circular Permutations} = (n - 1)!Circular Permutations=(n−1)!
  • Clockwise and Anticlockwise Indistinguishable (Necklaces / Garlands): Flipping the ring yields an identical arrangement, eliminating half the configurations: Ways=(n−1)!2\text{Ways} = \frac{(n - 1)!}{2}Ways=2(n−1)!​

2. Combinations​

A combination is a selection of items where the order of selection does not matter.

2.1 Formula and Properties​

The number of combinations of nnn distinct objects taken rrr at a time is: nCr=n!r!⋅(n−r)!=nPrr!^n C_r = \frac{n!}{r! \cdot (n - r)!} = \frac{^n P_r}{r!}nCr​=r!⋅(n−r)!n!​=r!nPr​​

Key Algebraic Properties​

  • Symmetry: nCr=nCn−r^n C_r = ^n C_{n - r}nCr​=nCn−r​
  • Boundary Values: nC0=nCn=1,nC1=n^n C_0 = ^n C_n = 1, \quad ^n C_1 = nnC0​=nCn​=1,nC1​=n
  • Pascal's Identity: nCr+nCr−1=n+1Cr^n C_r + ^n C_{r - 1} = ^{n + 1} C_rnCr​+nCr−1​=n+1Cr​
  • Equality Condition: If nCx=nCy,then either x=yor x+y=n\text{If } ^n C_x = ^n C_y, \quad \text{then either } x = y \quad \text{or } x + y = nIf nCx​=nCy​,then either x=yor x+y=n
  • Total Subsets (Sum of Combinations): nC0+nC1+nC2+⋯+nCn=2n^n C_0 + ^n C_1 + ^n C_2 + \dots + ^n C_n = 2^nnC0​+nC1​+nC2​+⋯+nCn​=2n

2.2 Geometric Combinations​

  • Number of straight lines formed by nnn points (no 3 collinear): Lines=nC2\text{Lines} = ^n C_2Lines=nC2​
  • If mmm points out of nnn are collinear: Lines=nC2−mC2+1\text{Lines} = ^n C_2 - ^m C_2 + 1Lines=nC2​−mC2​+1
  • Number of triangles formed by nnn points: Triangles=nC3−mC3\text{Triangles} = ^n C_3 - ^m C_3Triangles=nC3​−mC3​
  • Number of diagonals in an nnn-sided polygon: Diagonals=nC2−n=n(n−1)2−n=n(n−3)2\text{Diagonals} = ^n C_2 - n = \frac{n(n - 1)}{2} - n = \frac{n(n - 3)}{2}Diagonals=nC2​−n=2n(n−1)​−n=2n(n−3)​

3. Probability​

Probability quantifies the likelihood of occurrence of a random event.

3.1 Terminology​

  • Random Experiment: An experiment whose outcomes cannot be predicted with certainty in advance, but the set of all possible outcomes is known.
  • Sample Space (SSS): The set of all possible outcomes of a random experiment.
  • Event (EEE): Any subset of the sample space (E⊆SE \subseteq SE⊆S).

3.2 Types of Events​

  • Impossible Event (∅\emptyset∅): An event that cannot occur (P(∅)=0P(\emptyset) = 0P(∅)=0).
  • Sure / Certain Event (SSS): An event that always occurs (P(S)=1P(S) = 1P(S)=1).
  • Simple / Elementary Event: An event containing exactly one sample point.
  • Mutually Exclusive (Disjoint) Events: Two events that cannot occur simultaneously: A∩B=∅  ⟹  P(A∩B)=0A \cap B = \emptyset \implies P(A \cap B) = 0A∩B=∅⟹P(A∩B)=0
  • Independent Events: Occurrence of one event does not affect the occurrence of the other: P(A∩B)=P(A)×P(B)P(A \cap B) = P(A) \times P(B)P(A∩B)=P(A)×P(B)
  • Exhaustive Events: A set of events whose union covers the entire sample space: A1∪A2∪⋯∪Ak=S  ⟹  ∑P(Ai)=1 (if disjoint)A_1 \cup A_2 \cup \dots \cup A_k = S \implies \sum P(A_i) = 1 \text{ (if disjoint)}A1​∪A2​∪⋯∪Ak​=S⟹∑P(Ai​)=1 (if disjoint)
  • Complementary Event (E′E'E′ or Eˉ\bar{E}Eˉ): The non-occurrence of event EEE: P(E′)=1−P(E)P(E') = 1 - P(E)P(E′)=1−P(E)

3.3 Classical Definition of Probability​

If a trial results in nnn mutually exclusive, equally likely, and exhaustive outcomes, and mmm of them are favorable to event EEE: P(E)=Number of favorable outcomes mTotal number of possible outcomes n=n(E)n(S)P(E) = \frac{\text{Number of favorable outcomes } m}{\text{Total number of possible outcomes } n} = \frac{n(E)}{n(S)}P(E)=Total number of possible outcomes nNumber of favorable outcomes m​=n(S)n(E)​ 0≤P(E)≤10 \le P(E) \le 10≤P(E)≤1

3.4 Addition Theorem of Probability​

  • For any two arbitrary events AAA and BBB: P(A∪B)=P(A)+P(B)−P(A∩B)P(A \cup B) = P(A) + P(B) - P(A \cap B)P(A∪B)=P(A)+P(B)−P(A∩B)
  • For mutually exclusive events (A∩B=∅A \cap B = \emptysetA∩B=∅): P(A∪B)=P(A)+P(B)P(A \cup B) = P(A) + P(B)P(A∪B)=P(A)+P(B)
  • For three events A,B,CA, B, CA,B,C: P(A∪B∪C)=P(A)+P(B)+P(C)−P(A∩B)−P(B∩C)−P(A∩C)+P(A∩B∩C)P(A \cup B \cup C) = P(A) + P(B) + P(C) - P(A \cap B) - P(B \cap C) - P(A \cap C) + P(A \cap B \cap C)P(A∪B∪C)=P(A)+P(B)+P(C)−P(A∩B)−P(B∩C)−P(A∩C)+P(A∩B∩C)

3.5 Common Sample Space Reference Tables​

Standard Deck of 52 Cards​

  • Total: 52 cards divided into 4 suits of 13 cards each.
    • Red Suits (26): Hearts (13), Diamonds (13).
    • Black Suits (26): Spades (13), Clubs (13).
  • Ranks in each suit: Ace, 2, 3, 4, 5, 6, 7, 8, 9, 10, Jack, Queen, King.
  • Face Cards (Honors with faces): Jack, Queen, King (4×3=124 \times 3 = 124×3=12 cards).
  • Aces: 4 cards (one in each suit).

Rolling Two Standard Dice​

  • Total outcomes =6×6=36= 6 \times 6 = 36=6×6=36.
  • Sum distribution:
    • Sum=2\text{Sum} = 2Sum=2 or 121212: 1 way each
    • Sum=3\text{Sum} = 3Sum=3 or 111111: 2 ways each
    • Sum=4\text{Sum} = 4Sum=4 or 101010: 3 ways each
    • Sum=5\text{Sum} = 5Sum=5 or 999: 4 ways each
    • Sum=6\text{Sum} = 6Sum=6 or 888: 5 ways each
    • Sum=7\text{Sum} = 7Sum=7: 6 ways (most frequent)

4. Solved Problems and Exam Practice​

Problem 1 (Permutation of Words with Repeated Letters)​

How many different 8-letter words can be formed from the letters of the word COURTESY so that vowels are always together?

Solution:

  1. The word COURTESY has 8 distinct letters.
  2. Vowels: O, U, E (3 vowels).
  3. Consonants: C, R, T, S, Y (5 consonants).
  4. Bundle the 3 vowels as one single unit: (O,U,E)(O, U, E)(O,U,E).
  5. Total units to arrange =5 consonants+1 vowel-unit=6 units= 5 \text{ consonants} + 1 \text{ vowel-unit} = 6 \text{ units}=5 consonants+1 vowel-unit=6 units.
  6. Number of ways to arrange the 6 units =6!=720= 6! = 720=6!=720.
  7. The 3 vowels inside the unit can be arranged among themselves in 3!=63! = 63!=6 ways. Total Words=6!×3!=720×6=4,320\text{Total Words} = 6! \times 3! = 720 \times 6 = 4,320Total Words=6!×3!=720×6=4,320

Problem 2 (Permutation with Repetition)​

How many different words can be formed using the letters of the word MATHEMATICS?

Solution: Total letters n=11n = 11n=11. Letter frequencies:

  • M:2\text{M}: 2M:2
  • A:2\text{A}: 2A:2
  • T:2\text{T}: 2T:2
  • H:1,E:1,I:1,C:1,S:1\text{H}: 1, \text{E}: 1, \text{I}: 1, \text{C}: 1, \text{S}: 1H:1,E:1,I:1,C:1,S:1 Total Words=11!2!⋅2!⋅2!=39,916,8008=4,989,600\text{Total Words} = \frac{11!}{2! \cdot 2! \cdot 2!} = \frac{39,916,800}{8} = 4,989,600Total Words=2!⋅2!⋅2!11!​=839,916,800​=4,989,600

Problem 3 (Circular Permutation)​

In how many ways can 7 people sit around a circular table? In how many ways can 7 beads of different colors be strung on a necklace?

Solution:

  • For 7 people around a circular table: Ways=(7−1)!=6!=720\text{Ways} = (7 - 1)! = 6! = 720Ways=(7−1)!=6!=720
  • For 7 beads on a necklace (clockwise and counterclockwise are identical): Ways=(7−1)!2=6!2=7202=360\text{Ways} = \frac{(7 - 1)!}{2} = \frac{6!}{2} = \frac{720}{2} = 360Ways=2(7−1)!​=26!​=2720​=360

Problem 4 (Committee Selection Combination)​

A committee of 5 persons is to be formed from 6 men and 4 women. In how many ways can this be done if the committee must contain at least 2 women?

Solution: Possible team compositions:

  1. 2 women and 3 men: 4C2×6C3=6×20=120^4 C_2 \times ^6 C_3 = 6 \times 20 = 1204C2​×6C3​=6×20=120
  2. 3 women and 2 men: 4C3×6C2=4×15=60^4 C_3 \times ^6 C_2 = 4 \times 15 = 604C3​×6C2​=4×15=60
  3. 4 women and 1 man: 4C4×6C1=1×6=6^4 C_4 \times ^6 C_1 = 1 \times 6 = 64C4​×6C1​=1×6=6 Total Ways=120+60+6=186\text{Total Ways} = 120 + 60 + 6 = 186Total Ways=120+60+6=186

Problem 5 (Polygon Diagonals)​

Find the number of diagonals in an octagon (8-sided polygon).

Solution: n=8n = 8n=8 Diagonals=n(n−3)2=8×(8−3)2=8×52=20\text{Diagonals} = \frac{n(n - 3)}{2} = \frac{8 \times (8 - 3)}{2} = \frac{8 \times 5}{2} = 20Diagonals=2n(n−3)​=28×(8−3)​=28×5​=20

Problem 6 (Card Drawing Probability)​

A card is drawn at random from a well-shuffled pack of 52 playing cards. Find the probability that the card drawn is either a King or a Heart.

Solution:

  • Total cards n(S)=52n(S) = 52n(S)=52.
  • Let AAA be the event of drawing a King: n(A)=4n(A) = 4n(A)=4.
  • Let BBB be the event of drawing a Heart: n(B)=13n(B) = 13n(B)=13.
  • Intersection A∩BA \cap BA∩B (the King of Hearts): n(A∩B)=1n(A \cap B) = 1n(A∩B)=1. Using the addition theorem: P(A∪B)=P(A)+P(B)−P(A∩B)=452+1352−152=1652=413P(A \cup B) = P(A) + P(B) - P(A \cap B) = \frac{4}{52} + \frac{13}{52} - \frac{1}{52} = \frac{16}{52} = \frac{4}{13}P(A∪B)=P(A)+P(B)−P(A∩B)=524​+5213​−521​=5216​=134​

Problem 7 (Two Dice Sum Probability)​

In a simultaneous throw of two dice, what is the probability of getting a total sum of 8?

Solution: Total outcomes n(S)=6×6=36n(S) = 6 \times 6 = 36n(S)=6×6=36. Favorable pairs giving a sum of 8: (2,6),(3,5),(4,4),(5,3),(6,2)(2, 6), (3, 5), (4, 4), (5, 3), (6, 2)(2,6),(3,5),(4,4),(5,3),(6,2) Total favorable outcomes n(E)=5n(E) = 5n(E)=5. P(Sum=8)=536P(\text{Sum} = 8) = \frac{5}{36}P(Sum=8)=365​

Problem 8 (Urn Selection Probability)​

A bag contains 5 red balls, 4 green balls, and 3 blue balls. If 3 balls are drawn at random, find the probability that all 3 balls are red.

Solution: Total balls =5+4+3=12= 5 + 4 + 3 = 12=5+4+3=12. Total ways to draw 3 balls from 12: n(S)=12C3=12×11×103×2×1=220n(S) = ^{12} C_3 = \frac{12 \times 11 \times 10}{3 \times 2 \times 1} = 220n(S)=12C3​=3×2×112×11×10​=220 Ways to draw 3 red balls from 5: n(E)=5C3=5×42×1=10n(E) = ^5 C_3 = \frac{5 \times 4}{2 \times 1} = 10n(E)=5C3​=2×15×4​=10 P(All Red)=n(E)n(S)=10220=122P(\text{All Red}) = \frac{n(E)}{n(S)} = \frac{10}{220} = \frac{1}{22}P(All Red)=n(S)n(E)​=22010​=221​

Problem 9 (Independent Events Probability)​

AAA and BBB shoot at a target. The probability that AAA hits the target is 23\frac{2}{3}32​, and the probability that BBB hits the target is 34\frac{3}{4}43​. Find the probability that the target is hit at least once if both shoot independently.

Solution: Probability of AAA missing: P(A′)=1−23=13P(A') = 1 - \frac{2}{3} = \frac{1}{3}P(A′)=1−32​=31​. Probability of BBB missing: P(B′)=1−34=14P(B') = 1 - \frac{3}{4} = \frac{1}{4}P(B′)=1−43​=41​. Since the events are independent, probability that both miss: P(A′∩B′)=P(A′)×P(B′)=13×14=112P(A' \cap B') = P(A') \times P(B') = \frac{1}{3} \times \frac{1}{4} = \frac{1}{12}P(A′∩B′)=P(A′)×P(B′)=31​×41​=121​ Probability that target is hit at least once: P(At least one hit)=1−P(A′∩B′)=1−112=1112P(\text{At least one hit}) = 1 - P(A' \cap B') = 1 - \frac{1}{12} = \frac{11}{12}P(At least one hit)=1−P(A′∩B′)=1−121​=1211​

Problem 10 (Selection with Restrictions)​

From a group of 7 men and 6 women, 5 persons are to be selected to form a committee so that at least 3 men are there on the committee. In how many ways can it be done?

Solution: The combinations are:

  1. 3 men and 2 women: 7C3×6C2=35×15=525^7 C_3 \times ^6 C_2 = 35 \times 15 = 5257C3​×6C2​=35×15=525
  2. 4 men and 1 woman: 7C4×6C1=35×6=210^7 C_4 \times ^6 C_1 = 35 \times 6 = 2107C4​×6C1​=35×6=210
  3. 5 men and 0 women: 7C5×6C0=21×1=21^7 C_5 \times ^6 C_0 = 21 \times 1 = 217C5​×6C0​=21×1=21 Total Ways=525+210+21=756\text{Total Ways} = 525 + 210 + 21 = 756Total Ways=525+210+21=756

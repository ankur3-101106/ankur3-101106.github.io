TITLE

Series Analogy, Odd Man Out, Coding and Decoding​

1. Number and Letter Series​

A series is an ordered sequence of numbers or letters governed by a logical underlying mathematical or positional rule.

1.1 Types of Number Series​

  1. Arithmetic / Difference Series:
    • Constant Difference: Common difference d=Tk+1−Tkd = T_{k+1} - T_kd=Tk+1​−Tk​.
    • Variable Difference (Double-tier difference): The first differences form an arithmetic progression: Δ1=Tk+1−Tk,Δ2=Δ1,k+1−Δ1,k=constant\Delta_1 = T_{k+1} - T_k, \quad \Delta_2 = \Delta_{1, k+1} - \Delta_{1, k} = \text{constant}Δ1​=Tk+1​−Tk​,Δ2​=Δ1,k+1​−Δ1,k​=constant
  2. Geometric / Ratio Series:
    • Successive terms are multiplied or divided by a constant factor rrr: Tk+1=Tk×rT_{k+1} = T_k \times rTk+1​=Tk​×r.
  3. Power Series (Squares and Cubes):
    • Pure squares: n2  ⟹  1,4,9,16,25,36,49,64,…n^2 \implies 1, 4, 9, 16, 25, 36, 49, 64, \dotsn2⟹1,4,9,16,25,36,49,64,…
    • Pure cubes: n3  ⟹  1,8,27,64,125,216,343,…n^3 \implies 1, 8, 27, 64, 125, 216, 343, \dotsn3⟹1,8,27,64,125,216,343,…
    • Shifted squares: n2±1n^2 \pm 1n2±1 or n2±nn^2 \pm nn2±n
    • Shifted cubes: n3±1n^3 \pm 1n3±1 or n3±nn^3 \pm nn3±n
  4. Consecutive Integer Products:
    • Terms of the form n(n+1)n(n + 1)n(n+1): 1×2=2,2×3=6,3×4=12,4×5=20,5×6=30,…1 \times 2 = 2, \quad 2 \times 3 = 6, \quad 3 \times 4 = 12, \quad 4 \times 5 = 20, \quad 5 \times 6 = 30, \dots1×2=2,2×3=6,3×4=12,4×5=20,5×6=30,…
  5. Cumulative / Fibonacci Series:
    • Each term is the sum of the preceding two or three terms: Tn=Tn−1+Tn−2T_n = T_{n - 1} + T_{n - 2}Tn​=Tn−1​+Tn−2​
  6. Alternating / Interleaved Series:
    • Two independent series interwoven into alternating odd-indexed and even-indexed positions: T1,T3,T5,…andT2,T4,T6,…T_1, T_3, T_5, \dots \quad \text{and} \quad T_2, T_4, T_6, \dotsT1​,T3​,T5​,…andT2​,T4​,T6​,…

1.2 Odd Man Out (Wrong Number in Series)​

In "Odd Man Out" problems:

  1. Identify the consistent governing law obeyed by the majority of elements.
  2. Calculate the theoretical value required by the pattern at each step.
  3. Locate the single anomaly that violates the established succession.

2. Analogies​

An analogy tests the ability to recognize identical relationships between pairs of entities: A:B::C:DA : B :: C : DA:B::C:D (Read as "AAA is related to BBB in the same way as CCC is related to DDD").

2.1 Types of Analogies​

  1. Semantic / Word Analogies:
    • Worker and Tool: Carpenter : Saw :: Author : Pen
    • Worker and Product: Mason : Wall :: Poet : Poem
    • Cause and Effect: Fire : Smoke :: Infection : Fever
    • Country and Capital / Currency: India : New Delhi :: Japan : Tokyo
    • Individual and Category: Whale : Mammal :: Snake : Reptile
  2. Numerical Analogies:
    • Squares, cubes, prime transforms, or arithmetic scaling between pairs: 4:64::5:125(x:x3)4 : 64 :: 5 : 125 \quad (x : x^3)4:64::5:125(x:x3)
  3. Letter Analogies:
    • Positional shifts across alphabetical indices.

3. Coding and Decoding​

Coding is the transformation of a message into a cipher following a set of systematic rules. Decoding is reversing the cipher back to plain text.

3.4 Coding Methodologies​

  1. Letter-to-Letter Coding:
    • Forward/Backward Shifts: Each letter shifted by a uniform constant +k+k+k or alternating sequence (+1,−1,+2,−2+1, -1, +2, -2+1,−1,+2,−2).
    • Reverse Order: Word written in backward sequence.
    • Opposite Letter Mapping: Each letter replaced by its complementary pair letter.
  2. Letter-to-Number Coding:
    • Letters replaced directly by their positional values (A=1,B=2A=1, B=2A=1,B=2).
    • Sum of positional numbers: Code=∑Positions\text{Code} = \sum \text{Positions}Code=∑Positions
    • Sum multiplied by number of letters: Code=(∑Positions)×(Length)\text{Code} = \left(\sum \text{Positions}\right) \times (\text{Length})Code=(∑Positions)×(Length)
  3. Mixed Sentence / Word Coding (Deciphering by Elimination):
    • Compare statements pairwise.
    • A word appearing in two statements must correspond to the unique code word or digit shared between those two coded outputs.

4. Solved Problems and Exam Practice​

Problem 1 (Missing Number in Arithmetic Difference Series)​

Find the missing number in the series: 2,5,9,19,37,?2, 5, 9, 19, 37, ?2,5,9,19,37,?

Solution: Examine the pattern of differences or transitions:

  • 2×2+1=52 \times 2 + 1 = 52×2+1=5
  • 5×2−1=95 \times 2 - 1 = 95×2−1=9
  • 9×2+1=199 \times 2 + 1 = 199×2+1=19
  • 19×2−1=3719 \times 2 - 1 = 3719×2−1=37 The pattern is alternating: ×2+1,×2−1,×2+1,×2−1\times 2 + 1, \times 2 - 1, \times 2 + 1, \times 2 - 1×2+1,×2−1,×2+1,×2−1. Next term=37×2+1=74+1=75\text{Next term} = 37 \times 2 + 1 = 74 + 1 = 75Next term=37×2+1=74+1=75 The missing number is 75.

Problem 2 (Odd Man Out in Power Series)​

Find the odd number out in the following series: 9,16,25,36,125,169,196,2259, 16, 25, 36, 125, 169, 196, 2259,16,25,36,125,169,196,225

Solution: Analyze the elements:

  • 9=329 = 3^29=32
  • 16=4216 = 4^216=42
  • 25=5225 = 5^225=52
  • 36=6236 = 6^236=62
  • 125=53125 = 5^3125=53 (cube of 5, not a square of an integer)
  • 169=132169 = 13^2169=132
  • 196=142196 = 14^2196=142
  • 225=152225 = 15^2225=152 All elements in the sequence are perfect squares except 125, which is a perfect cube. The odd man out is 125.

Problem 3 (Consecutive Integer Products Series)​

Find the missing number in the series: 6,12,20,30,42,56,?6, 12, 20, 30, 42, 56, ?6,12,20,30,42,56,?

Solution: Express each term as the product of two consecutive integers:

  • 2×3=62 \times 3 = 62×3=6
  • 3×4=123 \times 4 = 123×4=12
  • 4×5=204 \times 5 = 204×5=20
  • 5×6=305 \times 6 = 305×6=30
  • 6×7=426 \times 7 = 426×7=42
  • 7×8=567 \times 8 = 567×8=56 Next term=8×9=72\text{Next term} = 8 \times 9 = 72Next term=8×9=72 Alternatively, examine first differences: 6,8,10,12,14,16  ⟹  56+16=726, 8, 10, 12, 14, 16 \implies 56 + 16 = 726,8,10,12,14,16⟹56+16=72. The missing number is 72.

Problem 4 (Alternating Interleaved Series)​

Find the next term in the series: 3,8,6,14,9,20,12,?3, 8, 6, 14, 9, 20, 12, ?3,8,6,14,9,20,12,?

Solution: Split the sequence into two interleaved sub-series:

  • Odd positions (1st,3rd,5th,7th1^{\text{st}}, 3^{\text{rd}}, 5^{\text{th}}, 7^{\text{th}}1st,3rd,5th,7th): 3,6,9,12(+3 each step)3, 6, 9, 12 \quad (+3 \text{ each step})3,6,9,12(+3 each step)
  • Even positions (2nd,4th,6th,8th2^{\text{nd}}, 4^{\text{th}}, 6^{\text{th}}, 8^{\text{th}}2nd,4th,6th,8th): 8,14,20,?(+6 each step)8, 14, 20, ? \quad (+6 \text{ each step})8,14,20,?(+6 each step) Next term=20+6=26\text{Next term} = 20 + 6 = 26Next term=20+6=26 The next term is 26.

Problem 5 (Semantic Analogy - Solar System Classification)​

Choose the odd entity from the group: (a) Mercury, (b) Venus, (c) Titan, (d) Earth

Solution:

  • Mercury, Venus, and Earth are primary planets revolving around the Sun in our solar system.
  • Titan is a planetary moon (natural satellite) of Saturn. The odd man out is (c) Titan.

Problem 6 (Letter Coding with Uniform Shift)​

If in a certain code language, MADRAS is coded as NBESBT, how is BOMBAY coded in that same language?

Solution: Observe the shift for each letter:

  • M(+1)→N\text{M} (+1) \to \text{N}M(+1)→N
  • A(+1)→B\text{A} (+1) \to \text{B}A(+1)→B
  • D(+1)→E\text{D} (+1) \to \text{E}D(+1)→E
  • R(+1)→S\text{R} (+1) \to \text{S}R(+1)→S
  • A(+1)→B\text{A} (+1) \to \text{B}A(+1)→B
  • S(+1)→T\text{S} (+1) \to \text{T}S(+1)→T Each letter is shifted forward by +1+1+1. Applying +1+1+1 to BOMBAY:
  • B(+1)→C\text{B} (+1) \to \text{C}B(+1)→C
  • O(+1)→P\text{O} (+1) \to \text{P}O(+1)→P
  • M(+1)→N\text{M} (+1) \to \text{N}M(+1)→N
  • B(+1)→C\text{B} (+1) \to \text{C}B(+1)→C
  • A(+1)→B\text{A} (+1) \to \text{B}A(+1)→B
  • Y(+1)→Z\text{Y} (+1) \to \text{Z}Y(+1)→Z BOMBAY is coded as CPNCBZ.

Problem 7 (Letter Shift with Decrement)​

If ORANGE is coded as MPYLEC, what is the underlying rule?

Solution: Compare positional values of corresponding letters:

  • O(15)→M(13):−2\text{O}(15) \to \text{M}(13): -2O(15)→M(13):−2
  • R(18)→P(16):−2\text{R}(18) \to \text{P}(16): -2R(18)→P(16):−2
  • A(1 or 27)→Y(25):−2\text{A}(1 \text{ or } 27) \to \text{Y}(25): -2A(1 or 27)→Y(25):−2
  • N(14)→L(12):−2\text{N}(14) \to \text{L}(12): -2N(14)→L(12):−2
  • G(7)→E(5):−2\text{G}(7) \to \text{E}(5): -2G(7)→E(5):−2
  • E(5)→C(3):−2\text{E}(5) \to \text{C}(3): -2E(5)→C(3):−2 The rule is a uniform decrement of −2-2−2 for each letter in the word.

Problem 8 (Number Coding - Sum of Positions)​

If A=1\text{A} = 1A=1, AND=19\text{AND} = 19AND=19, find the numerical code for BAT\text{BAT}BAT.

Solution:

  • A=1\text{A} = 1A=1
  • AND=A(1)+N(14)+D(4)=1+14+4=19\text{AND} = \text{A}(1) + \text{N}(14) + \text{D}(4) = 1 + 14 + 4 = 19AND=A(1)+N(14)+D(4)=1+14+4=19 For BAT\text{BAT}BAT: BAT=B(2)+A(1)+T(20)=2+1+20=23\text{BAT} = \text{B}(2) + \text{A}(1) + \text{T}(20) = 2 + 1 + 20 = 23BAT=B(2)+A(1)+T(20)=2+1+20=23 The numerical code for BAT is 23.

Problem 9 (Mixed Number Sentence Coding)​

In a code language:

  1. "the monster hunter" is coded as 324324324
  2. "will be the" is coded as 476476476
  3. "they are in" is coded as 158158158 Which digit represents "the"?

Solution:

  • Comparing Statement 1 and Statement 2:
    • Common word on LHS: "the"
    • Common digit on RHS: 444 (since 324∩476={4}324 \cap 476 = \{4\}324∩476={4}). Therefore, the digit representing "the" is 4.

Problem 10 (Mixed Sentence Elimination)​

Study the following coded phrases:

  • "Critical Rates Affects Growth" is coded as "su phi chi da"
  • "Economic Rates Need Growth" is coded as "phi zo da ti"
  • "Government Affects Economic Policies" is coded as "zo koo su ma" Find the code for "Critical".

Solution:

  1. Compare Statement 1 and Statement 2:
    • Shared words: "Rates", "Growth"
    • Shared codes: "phi", "da"
    • Thus, {Rates,Growth}={phi,da}\{ \text{Rates}, \text{Growth} \} = \{ \text{phi}, \text{da} \}{Rates,Growth}={phi,da}.
  2. Compare Statement 1 and Statement 3:
    • Shared word: "Affects"
    • Shared code: "su"
    • Thus, Affects=su\text{Affects} = \text{su}Affects=su.
  3. In Statement 1:
    • Words are: "Critical", "Rates", "Affects", "Growth".
    • We know: Affects=su\text{Affects} = \text{su}Affects=su and {Rates,Growth}={phi,da}\{ \text{Rates}, \text{Growth} \} = \{ \text{phi}, \text{da} \}{Rates,Growth}={phi,da}.
    • The only remaining word is "Critical", and the only remaining code is "chi". Therefore, the code for "Critical" is chi.
